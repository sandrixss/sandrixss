# Лабораторная работа: дерево решений с χ²

Авторы: Sandris Borkovskis, Dmitrijs Dunajs.

[Скачать Excel](./SBorkovskisDDunajs.xlsx?raw=true) · [Посмотреть дерево](./lemumu_koks_chi_square.png)

В книге находятся исходные 15 записей, методика, расчёты всех четырёх итераций, дерево, восемь правил и проверка каждой строки. Отчёт оформлен на латышском. Включены обычная сетка Excel, границы ячеек, фильтры и закреплённые заголовки.

Разбиение выбирается по максимальному χ². При равных значениях используется признак с меньшим числом различных значений в текущем узле; оставшееся равенство разрешается исходным порядком столбцов. Это правило описано в отчёте. Оно даёт четыре внутренних узла и восемь чистых листьев.

Дерево правильно классифицирует все 15 исходных записей. Это проверка на обучающих данных; точность на новых объектах не измерялась. Для другой таблицы нужно заново построить дерево.
